# iOS Resolution

Display properties of every iPhone, iPad, iPod touch and Apple Watch Apple ever made.

![iOS Resolution](metadata/ios-resolutions.png)

## Features

- **Browse all Apple devices** — iPhone, iPad, iPod touch, and Apple Watch
- **Filter by device family** — Quickly narrow down to the device type you need
- **Search** — Find any device by name
- **Detailed specifications** — View logical and physical resolutions, PPI, scale factor, screen diagonal, aspect ratio, and release date
- **Quick copy actions** — Copy any specification to clipboard with a single keystroke
